Augflow Jira Bridge

Targets augflow serve (default port 4400). Import uses POST /api/tasks/jira/import-by-key and optionally POST /api/cards/start.

Default http://localhost:4400. Local dev, LAN, or HTTPS team server. Chrome will ask to allow the host on first save or test.

Project identifier from Augflow’s project switcher (registry key, not necessarily a filesystem path).

Repository slug for the selected default project. Load projects via Test connection first.

Stored only in extension sync storage; never injected into Jira pages.

Shortcuts on Jira

  • Import current issue (default project & auto-start setting)
  • Import with options (pick project, repository & import / import + start)
  • Import with options (floating button on the page) Shift + click
  • Import with options (extension toolbar icon menu) Right-click → Import with options…

Customize keyboard shortcuts in your browser if these conflict with other apps.
