Augflow Jira Bridge

Targets augflow serve on your machine (default port 4400). Import uses POST /api/tasks/jira/import-by-key and optionally POST /api/cards/start.

Default http://localhost:4400. Must be http://localhost or http://127.0.0.1 with an allowlisted port.

Absolute path to the Augflow-registered project on this machine.

Stored only in extension sync storage; never injected into Jira pages.
